## 二、PWA 永久「重连中」（提交 e39cc2f）

- **根因（闭环复现实锤）**：前端用原生 `EventSource`，浏览器自动重连只覆盖网络层断开；重连请求拿到非 200/非 event-stream 响应（生产走 cloudflared 隧道，断流/重启窗口回 502/52x）时 `readyState=CLOSED` 且**永不重试**。旧 `onerror` 只重载数据不重建连接 → 永久卡「重连中」；强刷=重建 EventSource 所以立刻恢复。
- **排除项**：sw.js 空壳透传（fetch 不 respondWith）；服务端 15s keepalive 正常。
- **修复**：`onerror` 检测 `CLOSED` → 指数退避重建（500ms 起倍增、封顶 30s、连上复位）；`CONNECTING` 仍交浏览器；保留 3s reload 兜底；卸载清理不变。
- **证据**：修复前 CDP 拦截首请求回 502 → 25s 观察窗零重试卡死；修复后同场景 0.5s 内二次连接恢复「实时」。P1–P4 回归全绿。
