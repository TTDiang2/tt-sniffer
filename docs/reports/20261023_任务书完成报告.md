## 2. 任务 B：风险×避险·当日新闻点 气泡贴边（§5.1）——完成（方案 1）

### 诊断（改前基线，2026-10-23 真实数据 713 条带 impacts）

```
[old 口径(均值x100)] 有点新闻 29 条；坐标在轴线上(x=0或y=0) 22 条（76%）；
贴边(|坐标|=100) 29 条（100%）；去重坐标 5 个
top 坐标: [((0, 100), 21), ((-100, -100), 5), ((100, -100), 1), ((100, 0), 1), ((100, 100), 1)]
```

任务书根因判断成立：`_side_score` 均值口径下只要有票必 ±100，单边新闻全落在四条轴射线端点。

### 修法（方案 1：连续强度 + 证据量收缩，保留象限语义）

- `app/charts.py` `_side_score`：净票方向 × `tanh(n/2) × 100`——1 票≈±46、2 票≈±76、3 票≈±91，证据越足越接近 ±100；混合票向净方向收敛；无票仍 None（不画）。`day_point`（14 日轨迹，用户已满意）**不动**。
- 前端 `ScatterSvg`：值域 [-110,110] 线性映射（±100 档位永不贴框）；**单边观点空心+虚线描边、双侧实心**（`sides` 字段驱动）；tooltip 补「单边/双侧观点」。

### 改后对照（同日同数据）

```
[cur 当前实现] 有点新闻 29 条；贴边(|坐标|=100) 0 条（0%）；去重坐标 5 个
top 坐标: [((0, 46), 21), ((-46, -46), 5), ((91, -46), 1), ((76, 0), 1), ((46, 46), 1)]
```

贴边 100% → 0%；坐标按证据量分层，散点可区分单边/双侧。同口径在 8788 隔离实例的真实历史日（2026-10-16）上复验：`(0,46,haven) / (-91,-76,both) / (91,-46,both) …`。

受影响既有断言同步：`test_news_point_both_sides`（100→76）、`test_server.py` scatter 端点断言（100→46）。
